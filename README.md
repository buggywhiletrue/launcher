### 원본 프로젝트 및 감사

이 런처는 [shuabritze의 Mushroom Launcher](https://github.com/shuabritze/mushroom-launcher)를 기반으로 수정한 비공식 파생 프로젝트입니다.
원본 런처를 개발하고 공개해 주신 [shuabritze](https://github.com/shuabritze)와 기여자분들께 감사드립니다.

본 버전은 한국 플레이어의 이용 환경에 맞추기 위해 다음 사항을 독립적으로 수정·관리합니다.

- KMS2 단독 데이터를 포함한 전용 클라이언트의 배포 경로
- 위 데이터의 업데이트 및 최적화
- GitHub Releases 기반 자동 다운로드 및 파일 검증
- 관련 서버 및 실행 환경 설정

본 프로젝트의 수정사항과 배포는 원본 개발자가 직접 제공하거나 보증하는 것이 아니며, 수정본과 관련된 문의는 원본 저장소가 아닌 이 저장소에서 처리합니다.
